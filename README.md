
# AI Tracefinder_Milestone_1

The objective of this milestone is to gather a collection of scanned document images dataset obtained from various scanner devices, systematically organize and annotate the data, examine fundamental image characteristics, and apply preprocessing pipeline for identification of particular scanner identification.Here,preprocessing techniques are used to normalize the dataset for subsequent machine learning or image analysis applications.

## Objective
1.Denoising the images.

2.Resizing the images.

3.Converting to grayscale (if needed).

4.Normalizing pixels of image into 512x512.
